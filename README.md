# Parkinson – Teclas e Dedos

## Sobre o projeto

Este projeto de pesquisa tem como objetivo desenvolver e validar um sistema multimodal de aquisição de dados durante a digitação em teclado físico.

O sistema deverá permitir o registro e a sincronização de informações como:

- Teclas pressionadas e liberadas.
- Tempo de pressionamento das teclas.
- Identificação do dedo e da mão utilizados.
- Pressão ou força exercida.
- Sinais de movimento dos dedos e das mãos.

Os dados coletados serão organizados para apoiar pesquisas sobre manifestações motoras da doença de Parkinson.

## Organização do repositório

- `src/` — Código-fonte dos programas.
- `docs/` — Documentação e dicionário de dados.
- `data/exemplos/` — Arquivos de exemplo para testes.
- `tests/` — Testes dos programas.
